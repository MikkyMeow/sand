# Grain of Sand · Backend

Fastify + Socket.io сервис, который обслуживает мультиплеерные сессии, валидирует входящие события и бродкастит состояние арены по фиксированному тикрейту.

## Стек

- Fastify 5 — HTTP слой + health чек.
- Socket.io 4 — двусторонний канал с фронтендом.
- TypeScript + ts-node-dev — комфортная разработка.
- Zod — валидация входящих сообщений.

## Скрипты

| Команда | Описание |
| ------- | -------- |
| `npm run dev` | локальный запуск с перезапуском при изменениях |
| `npm run build` | компиляция TypeScript → `dist/` |
| `npm run start` | стартует уже собранный JS |

## Переменные окружения

Скопируйте `.env.example` → `.env.local` и при необходимости измените значения.

| Переменная | Значение по умолчанию | Назначение |
| ---------- | --------------------- | ---------- |
| `PORT` | `4000` | HTTP/WS порт |
| `CLIENT_ORIGINS` | `http://localhost:5173` | Разрешённые источники (можно перечислить через запятую) |
| `MULTIPLAYER_TICK_RATE` | `30` | Сколько раз в секунду рассылается `world:state` |

## Протокол событий

- `world:state` — периодический снепшот всех игроков.
- `session:joined` — ответ новому игроку (его `playerId` + текущий мир).
- `player:update` — событие от клиента с новыми координатами/поворотом.
- `player:left` — бродкаст при отключении.

Все payload'ы валидируются на сервере, поэтому из коробки можно безопасно прототипировать механику.
